# 🚀 Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/umarsharook/Portfolio.git
cd Portfolio
```

---

## 2️⃣ Open in Browser

Simply open:

```bash
index.html
```

or run with Live Server in VS Code.

---

# ▶️ Deployment

## Deploy on GitHub Pages

1. Go to Repository Settings
2. Navigate to Pages
3. Select branch:
   - `main`
4. Save changes

Your portfolio will be live at:

```bash
https://your-username.github.io/Portfolio/
```

---

## Deploy on Vercel

```bash
npm install -g vercel
vercel
```
